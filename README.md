# Diana Voice

Голос как MCP-сервер для macOS. Скачал, поставил, подключил — у агента появились
уши и рот.

**Статус: задание, кода нет.** Читать [BRIEF.md](BRIEF.md).

```
voice_speak   — синтез речи, произносит вслух
voice_listen  — слушает микрофон, возвращает текст
```

Внутри — то, что уже работает в Diana: Whisper Large v3 Turbo на Metal (русский
3.31% WER, смешанная ru-en речь 24.31%, p50 ~240 мс) и Qwen3-TTS с клонированием
голоса. Всё локально, без облака.

## Перед первой строкой кода

1. Закрыть лицензионный аудит — [BRIEF.md §5](BRIEF.md#5-лицензии--гейт-перед-публикацией)
2. Проверить, доходит ли TCC-разрешение микрофона до stdio-процесса внутри
   подписанного бандла — [BRIEF.md §4](BRIEF.md#4-что-придётся-написать-заново)

Оба пункта определяют компоновку. Пока они открыты, писать нечего.
